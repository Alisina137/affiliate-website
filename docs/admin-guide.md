# Admin Guide

## Accessing the Admin Panel
1. Sign in with admin credentials
2. Navigate to /admin
3. You'll see the dashboard

## Dashboard Overview
- Total products, reviews, and users
- Recent activity feed
- Quick action buttons

## Managing Products
1. Go to Products → Products
2. Click "New Product"
3. Fill in product details
4. Save or publish

## Managing Reviews
1. Go to Content → Reviews
2. Click "New Review"
3. Select a product
4. Write the review
5. Save as draft or publish

## Managing Categories
1. Go to Products → Categories
2. Click "New Category"
3. Fill in category details
4. Save

## Managing Brands
1. Go to Products → Brands
2. Click "New Brand"
3. Fill in brand details
4. Save

## AI Content Studio
1. Go to AI → AI Content Studio
2. Select content type
3. Enter topic and details
4. Click "AI Generate"
5. Edit the generated content
6. Save or publish

## Affiliate Management
1. Go to Monetization → Affiliate Links
2. Click "New Link"
3. Enter affiliate URL
4. Assign to a product
5. Save

## Newsletter Management
1. Go to Newsletter
2. View subscribers list
3. Send campaigns
4. Track performance
